# NumPasso

Plataforma desenvolvida para auxiliar pessoas com discalculia no aprendizado da matemática de forma acessível e intuitiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- PHP

## Funcionalidades

- Página inicial responsiva
- Blog informativo
- Página de contato
- Interface acessível
- Design moderno e intuitivo

## Objetivo

Criar um ambiente digital acessível que facilite o aprendizado matemático para pessoas com discalculia.

## Responsividade

O projeto foi desenvolvido utilizando abordagem mobile first.
